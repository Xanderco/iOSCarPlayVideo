# App Review risk checklist: DashCast

Each risk is mapped to the App Store Review Guideline it touches, with the fix that is already in this repo
or the action still needed. Status: ✅ done in repo · ⚠️ owner/other-session action needed · ℹ️ decision for the owner.

> Scope note: this branch must not edit `DashCast/CarPlay/`, `WebVideoBrowserView`, `PlaylistStore`,
> `IPTVParser` or the Cast views, because other work sessions own them. Fixes in those files are listed as ⚠️ with exact
> pointers so the owning session can apply them.

## Pre-submission run-through

1. Fix the ⚠️ items in #1, #2, #4 and #7 (Cast, CarPlay and web-browser sessions).
2. Host the privacy policy, support page and `reviewer-demo.m3u` (with owner-hosted CC BY media). Then test the demo on a device.
3. Run the **App Store Media** workflow, download `appstore-screenshots-framed`, and review every image against #3 and #4.
4. In App Store Connect, enter the metadata from `AppStoreMedia/metadata.md`, the age rating (§7), the privacy label (§8) and the review notes (§9).
5. Create the `com.dashcast.lifetime` IAP with a review screenshot and submit it with the build.
