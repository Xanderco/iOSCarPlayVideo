## 1. How you must work (non-negotiable)

- **You are on Windows. You cannot compile Swift or run iOS tests.** GitHub Actions CI is your compiler and test runner.
  - Push your branch → `gh run list -R Xanderco/iOSCarPlayVideo -b <branch> -L 1` → when finished, `gh run view <id> -R Xanderco/iOSCarPlayVideo --log-failed` and search for `error:` / `failed`.

- **Base branch:** `claude/ci-and-core-fixes` (PR #14 → `main`). If #14 has been merged by the owner, use `main`. Run `git fetch origin` and check the journal first.

- **Never** move an issue to *Done* yourself without a merged PR. **Never** disable, skip or delete a test to make CI pass.
- **Small diffs.** Touch only the files the issue names. If another open PR touches the same files, wait or coordinate in a comment.
- **CI minutes:** if the repository is private again, every macOS minute is billed ×10. Batch your changes; don't push for every typo.
- **No copying competitors** (CarDash, CarTV): no traced layouts, copied strings, logos or screenshots. Inspiration only (D2, D4).
- **Monetization is fixed:** one non-consumable `pro.lifetime`, USD 19.99, **no subscriptions, no trials** (D1).
- **Never** add the word "CarPlay" to App Store metadata, and never add third-party content/streams or DRM services (D5, D6).
- Secrets: never commit keys. (The PACA key in `.paperclip/agents/*/config.json` is legacy; see issue H below.)
